# BonArt Creative 🎨💻

Portfolio and business website for **BonArt Creative**, a design and web development studio focused on creating digital experiences and solutions for real clients.

The website showcases our services, selected projects, studio presentation, testimonials and direct contact options.

---

## Overview

BonArt Creative is the digital showcase of our design and development studio.

The website was built to:

- Present our web development and design services
- Showcase completed client projects
- Introduce the studio and our work
- Share client testimonials
- Provide a direct contact channel through WhatsApp

---

## Key Features

- 🎨 Modern responsive design
- 💼 Services presentation
- 🧩 Client project showcase
- 💬 Testimonials section
- 📱 Mobile-friendly experience
- ⚡ Static site generation for fast performance
- 🎬 Custom animations and visual interactions
- ♿ Reduced-motion support
- 📲 Direct WhatsApp contact integration

---

## Tech Stack

- Astro 6

- CSS

- Prettier
- pnpm
